# Recording checklist

- [ ] Use a fresh browser profile and the public sandbox only.
- [ ] Do not display API keys, bearer headers, `.env` files, WorkOS keys,
      AetherHost controls, database records, or terminal history.
- [ ] Demonstrate one failing (`extra-host`) and one passing
      (`clean-relay`) fixture.
- [ ] State that `ship_with_conditions` still needs human sign-off.
- [ ] Show the green GitHub Actions workflow or test results.
- [ ] Keep the finished video between 2:00 and 2:45.
- [ ] Add captions and a short LinkedIn/GitHub description.
- [ ] Watch the exported video once with sound off to confirm the UI itself
      tells the story.
