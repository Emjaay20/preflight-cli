# AI-assisted video brief

Use this after recording the real screen capture. A polished screen recording
is more credible for an engineering application than a synthetic product demo.

## Prompt for an AI editor or voice-over tool

> Edit this 2 minute 30 second screen recording for a backend engineering job
> application. Keep all interface text, verdicts, architecture, and code
> claims accurate. Add clean captions, remove pauses and mouse dead time, and
> use restrained cuts only. Do not invent dashboards, statistics, customers,
> security guarantees, integrations, or product features. Keep a calm,
> technical, confident voice. Emphasize: TypeScript control plane, Rust static
> scanner, asynchronous queues, tenant isolation, observability, archive
> safeguards, and mandatory human sign-off. Export 1080p landscape MP4 with
> burned-in captions.

## What not to generate

- A fake terminal, fake monitoring graphs, or invented users.
- A claim that Preflight automatically ships releases.
- Claims of malware detection, production SSO, or enterprise customers.
- Any reconstruction of API keys or private infrastructure screens.
